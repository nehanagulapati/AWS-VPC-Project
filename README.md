# AWS-VPC-Project
AWS VPC project with public and private subnets,EC2 instances and connectivity testing.
AWS VPC Project

Project Overview

This project demonstrates the creation and configuration of an Amazon Web Services (AWS) Virtual Private Cloud (VPC). It includes subnet configuration, EC2 instances, security groups, and network connectivity testing.

Objectives

- Create and understand an AWS VPC.
- Configure public and private subnets.
- Understand route tables and network routing.
- Launch EC2 instances.
- Configure security groups.
- Test connectivity between instances.

AWS Services Used

- Amazon VPC
- Amazon EC2
- Subnets
- Route Tables
- Security Groups

Implementation

1. Created and explored VPC networking resources.
2. Configured public and private subnets.
3. Launched EC2 instances.
4. Reviewed security group rules.
5. Performed ping tests to check network connectivity.

Testing and Results

Connectivity tests were performed between EC2 instances. The recorded ping tests showed successful replies with 0% packet loss for the tested connections.
